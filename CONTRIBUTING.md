# Contributing

Please read [`sindresorhus/awesome`'s contributing guidelines](https://github.com/sindresorhus/awesome/blob/main/pull_request_template.md) for general style expectations — this list follows the same conventions.

Guidelines:

- Search existing entries before adding a new one to avoid duplicates.
- Add one entry per line, in the relevant section, using the format: `- [Name](link) - Description.` (description starts with a capital letter and ends with a period).
- Keep descriptions factual and concise. If a claim is notable but hard to verify (a viral demo, a community project, a single-source report), say so explicitly rather than stating it as settled fact.
- Distinguish licenses carefully: MaleCNS data is CC BY 4.0 (commercial use fine), FlyWire/FAFB data is CC BY-NC 4.0 (non-commercial only). Note the correct license when adding anything derived from either dataset.
- Order entries within a section alphabetically unless chronological order is more informative (e.g. dataset release history).
- Check that links resolve and point to the canonical/primary source (official project page or repo, not a mirror or news aggregator) where possible.
- One pull request per addition/change makes review easier, but small batches of closely related additions are fine.

By contributing, you agree that your contributions will be licensed under the [CC0 license](LICENSE) that covers this list's content.
